## 5. span 与 string_view — 零拷贝区间视图（整节）

C++17 的 `std::string_view` 和 C++20 的 `std::span` 共同构成了零拷贝区间视图体系：

| 类型 | 作用 | 引入版本 |
|------|------|----------|
| `std::string_view` | 字符串的只读视图 | C++17 |
| `std::span<T>` | 连续内存的视图 | C++20 |

```cpp
#include <span>
#include <string_view>

// string_view：不需要拷贝字符串
void process(std::string_view sv) {
    auto words = sv | std::views::split(' ');
}

// span：不需要拷贝数组
void sum(std::span<const int> data) {
    int total = 0;
    for (int x : data) total += x;
}
// sum(std::vector<int>{...});  // OK
// sum(std::array<int, 5>{...}); // OK
// sum(C数组);                    // OK
```

**价值：**
- 统一接口：`span<const int>` 兼容 `vector`、`array`、C 数组
- 零拷贝：只是指针+长度的薄包装
- 配合 Ranges 使用，做到"数据在哪里，View 就在哪里"
